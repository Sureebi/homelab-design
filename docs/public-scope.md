# Public Scope

This repository is designed for GitHub and portfolio use. It should present the homelab as a professional infrastructure project without exposing operational details.

## Include

- High-level network zones
- Device roles
- Physical and virtual host roles
- Service categories
- Public architecture decisions
- Clean topology diagrams
- A short explanation of what the homelab demonstrates

## Do Not Include

- Raw router, firewall, Proxmox, Linux, or Docker outputs
- Public IP addresses
- Credentials, tokens, keys, certificates, or private configuration
- MAC addresses or serial numbers
- Exact WAN configuration
- Sensitive port forwarding details
- Private domains or hostnames
- Screenshots from admin panels
- Personal device details that are not relevant to the portfolio

## Documentation Style

The public documentation should read like a polished infrastructure case study:

- What the homelab does
- Which major components exist
- How the main layers relate to each other
- What skills the project demonstrates
- Which security and privacy boundaries are intentionally kept out of public view

The detailed source data used to build the diagram should remain private.
